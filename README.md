# Task 6: Text Analysis

## Aim
Practise basic text processing techniques that are useful in natural language processing.

## What the notebook does
- Stores a sample text of three sentences.
- Counts the words and characters, with and without spaces.
- Counts the vowels, ignoring letter case.
- Finds the repeated words, ignoring case and punctuation, using `collections.Counter`.
- Checks the counts against the original text.
- Answers the three interview questions.
